# Recipes

Each recipe is one piece of recurring work, written so that Cowork starts from a proven design rather than a blank page.

| File or folder | What it holds |
|---|---|
| `recipe.md` | The recipe in plain words: the work, the problem, the inputs, the steps, the result, who decides and how to measure it |
| `skill/` | The skill starting point: SKILL.md with placeholders, scripts and test cases |
| `example/` | A finished example of the result. Its preview picture sits on the Pages site |
| `sample-data/` | Invented inputs, so that people can try the recipe before Cowork reads their own files |
| `sizing.json` | The questions for the business case and the kinds of spend that can stop |

## Rules for every recipe

- No customer names, no customer figures and no counts of customers.
- Figures in examples and sample data are invented, and say so.
- Office files and PDFs carry no sensitivity labels.
- A recipe's skill stays within 19 companion files, 5 MB per file and 10 MB in total.
