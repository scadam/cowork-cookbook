# Month-end variance commentary

| Part | This recipe |
|---|---|
| The work | The variance commentary in the monthly management pack |
| The problem | Problems are found late, explanations arrive incomplete, and several versions go round before the pack is accepted |
| Inputs | Locked-period ledger extract, approved budget and forecast, the variance workbook, last month's pack, and explanations from budget owners |
| Steps | 1. Register the inputs and tie them out. 2. Apply the materiality rules. 3. Draft the commentary, giving every statement a source and an evidence status. 4. Check the explanations against the evidence. 5. Draft questions to owners without sending them. 6. Assemble the draft pack |
| Result | A Word draft in the house template, a list of open questions and a register of sources |
| What good looks like | See `example/` and the preview picture on the Pages site |
| Who decides | The analyst confirms the inputs. The controller approves the pack. Cowork sends and releases nothing |
| What to measure | Packs accepted at first review. Unsupported statements reaching review |
| Sizing | See `sizing.json` |
